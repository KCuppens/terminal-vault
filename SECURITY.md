# Security Policy

## Supported Versions

Terminal Vault is under active development. Only the latest release receives security updates.

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

To report a vulnerability:
1. Use GitHub's private security advisory reporting: navigate to the **Security** tab of this repository and click **Report a vulnerability**.
2. Alternatively, email the maintainer directly at `kobecuppens@gmail.com` with the subject line `[SECURITY] Terminal Vault`.

Include:
- A description of the vulnerability and attack scenario.
- Steps to reproduce or proof-of-concept code.
- Impact on vault encryption, secrets, or SSH sessions.

You will receive an acknowledgment within 48 hours. Fixes are prioritized and published in a security advisory alongside a patched release.
